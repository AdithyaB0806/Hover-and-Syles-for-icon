# 🌐 Social Media Hover Icons (HTML + CSS)

A beautiful, responsive social media icon UI with hover animations using Font Awesome and pure CSS. Each icon spins and reveals its brand color with a smooth transition effect.

## 📜 How to Use

1. Clone or download this repo
2. Open `index.html` in your browser
3. Make sure you're connected to the internet for Font Awesome to load

---

## 💡 Customize This

You can:
- Change the social icons (`<i class="fa-brands fa-...">`)
- Update the colors in `:nth-child(n) a:before`
- Add more icons or animations (like bounce or glow)
- Add links to real social profiles in the `<a href="#">` tags
